        📋 手動でテストシナリオを作成する方法

        🎯 概要

        AIが生成するテストシナリオに満足できない場合、手動でJSONファイルを作成してより精密なテストを実行できます。

        💡 ヒント: 手動作成により、AIでは対応できない複雑なユーザーフローや特定の要素を正確にテストできます。

        📁 ファイルの配置場所

        以下のディレクトリに手動でJSONファイルを作成してください：

        test-results/route_yymmddhhmmss.json

        ファイル名の形式：route_ + 年月日時分秒 + .json

        例：route_250623145230.json (2025年06月23日 14時52分30秒)

        📝 JSON構造

        以下の構造でJSONファイルを作成してください：

        {
  "scenario_id": "scenario_manual_test_001",
  "route_id": "manual_test_001",
  "steps": [
    {
      "label": "ステップの説明",
      "action": "アクション名",
      "target": "セレクタまたはURL",
      "value": "入力値（オプション）"
    }
  ]
}

        🔧 利用可能なアクション

        • load - ページを読み込む
        • click - 要素をクリックする
        • fill - 入力フィールドに値を入力する
        • assertVisible - 要素が表示されていることを確認する
        • assertNotVisible - 要素が表示されていないことを確認する
        • waitForSelector - 要素が現れるまで待機する
        • waitForURL - 特定のURLに遷移するまで待機する

        📋 完全な例

        {
  "scenario_id": "scenario_manual_login_test",
  "route_id": "manual_login_test",
  "steps": [
    {
      "label": "ログインページを開く",
      "action": "load",
      "target": "https://example.com/login"
    },
    {
      "label": "ユーザー名を入力",
      "action": "fill",
      "target": "input[name='username']",
      "value": "testuser"
    },
    {
      "label": "パスワードを入力",
      "action": "fill",
      "target": "input[name='password']",
      "value": "testpass123"
    },
    {
      "label": "ログインボタンをクリック",
      "action": "click",
      "target": "button[type='submit']"
    },
    {
      "label": "ダッシュボードページに遷移確認",
      "action": "waitForURL",
      "target": "**/dashboard**"
    },
    {
      "label": "ようこそメッセージが表示されることを確認",
      "action": "assertVisible",
      "target": ".welcome-message"
    }
  ]
}

        ⚠️ 注意事項

        • JSONの構文エラーがないよう注意してください
        • セレクタは実際にページに存在する要素を指定してください
        • 複数の候補セレクタをカンマ区切りで指定できます（例："h1, .title, #main-title"）
        • ファイル保存後、テスト実行ボタンで自動的に最新ファイルが読み込まれます

        🔍 セレクタのコツ

        • F12コピー（推奨）: 開発者ツールで要素を右クリック → Copy → Copy selector
        • ID選択: #element-id
        • クラス選択: .class-name
        • 属性選択: input[type="email"]
        • テキスト選択: text=ログイン
        • 複合選択: form input[type="submit"]
        • 複数候補: button, .btn, [type="submit"]
        🚀 プロのコツ: F12の「Copy selector」機能を使えば、複雑なセレクタも簡単に取得できます！エスケープ文字も自動処理されるので安心です。
